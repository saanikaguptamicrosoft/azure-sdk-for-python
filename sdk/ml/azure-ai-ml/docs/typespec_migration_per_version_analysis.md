# TypeSpec Migration — Per-Version Analysis

Tracking analysis for each API version being migrated from autorest-generated clients to TypeSpec-generated clients in `azure-ai-ml`.

For every version we determine:
1. **Scope decision** — can the version be deprecated/removed from SDK, or must it be migrated?
2. **TypeSpec availability** — does upstream `azure-rest-api-specs` have TypeSpec for this version?
3. **Local-fork delta status** — are there differences between our local swagger and upstream, and are they used by SDK code?
4. **Next steps**
